# Weather Tool（天气查询小工具）

一个用 Python 调用免费天气接口的入门项目：输入城市名，返回实时天气。
配套 pytest 接口自动化测试，可一键验证接口是否正常。

## 功能

- 输入城市名，返回实时天气（天气状况、温度、风速）
- 断网或城市名错误时返回友好提示，程序不会崩溃

## 技术栈

- Python 3.11
- requests（HTTP 请求）
- pytest（接口自动化测试）

## 使用方法

```bash
python weather.py
```

输入城市名（如：重庆、彭水），回车即可看到天气。

## 运行测试

```bash
python -m pytest test_weather.py -v
```

## 测试用例覆盖

- 正常城市：能查到非空天气，且包含温度符号
- 接口状态：返回状态码 200
- 异常城市：返回友好提示而非崩溃
